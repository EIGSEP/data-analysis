# Bench runs

One folder per bench session of the receiver calibration measurement, named
`<UTC date>_<tag>`. Each folder's `README.md` records the setup as built, the
run log, where the data are, and the gaps against the requirements in
[`../receiver_calibration_lab_protocol.md`](../receiver_calibration_lab_protocol.md).
Records are not edited after their run; compare two runs' records to see what
changed on the bench.

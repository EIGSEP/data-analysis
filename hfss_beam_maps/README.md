# hfss_beam_maps

`bowtie_beam.npz` — Dominic's HFSS bowtie beam maps, 52 frequency slices
on a HEALPix grid (`beam_cart`, `gain_th`, `gain_ph`, `freqs`, `nside`).

## This is a copy. The canonical one is in `eigsep_data`

When the package split out of this repo (2026-09-17) this file was
**copied, not moved**, so that existing notebook paths kept resolving on
the day of the split. The copy that `eigsep_data.beam_sim.read_beam()`
reads — and the one that gets updated — is the one in
https://github.com/EIGSEP/eigsep_data.

**If the beam map is ever reissued, it lands in `eigsep_data` and this
copy gets deleted, not updated.** Do not edit this file; two diverging
38 MB binaries with no way to tell which is current is the exact failure
this note exists to prevent.

Current contents match `eigsep_data` as of the split: blob
`53dded829790d4d60fb4e9255246e0de3d2a6367`, which includes Dominic's
2026-09-16 frequency-label correction (`freqs` was uniformly low by one
3.90625 MHz HFSS grid step; `beam_cart`/`gain_th`/`gain_ph` were never
affected).
